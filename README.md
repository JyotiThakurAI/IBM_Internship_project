# Telco Customer Churn & Retention Analytics

**Author:** Jyoti Thakur  
**Technology Stack:** Python, Pandas, Scikit-Learn, Streamlit, Seaborn, Matplotlib  

---

## Project Overview
This project provides an end-to-end Data Analytics and Machine Learning pipeline designed to predict customer churn in the telecommunications sector. By analyzing customer demographics, account characteristics, and service usage, the system identifies high-risk churn customers and provides actionable retention strategies.

---

## Key Deliverables
- **Data Cleaning & Engineering:** Handled missing values, converted data types, and applied categorical encoding.
- **Exploratory Data Analysis:** Analyzed 5 key feature correlations affecting customer retention.
- **Predictive Machine Learning:** Trained a Random Forest Classifier achieving ~80% accuracy.
- **Interactive Dashboard:** Built a Streamlit web application (`app.py`) for live prediction and data exploration.
